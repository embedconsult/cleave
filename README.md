# Cleave

Tools for interacting with Fossil and agents using OCX
records and hooks. 

First target is a BeagleY-AI distro SD card image
that boots into a Fossil server used to develop the
voice controlled app itself. Hardware as an audio
board and microphone/speaker. Distro base is BQ2.
Bootloader and kernel based on Armbian versions.

Second target is BeagleBadge over Bluetooth speakers
in a car. 

Third target is to help fill in gaps on the Stone
iPhone app related to voice commands.
